Download the file for your computer, then follow the steps. Nothing else needs to be installed.

| Computer | File | Steps |
|---|---|---|
| Windows | `AcademicJobTracker-…-windows-setup.exe` | Run it. If Windows says "Windows protected your PC", click *More info → Run anyway* (the installer is not code-signed). Start the tracker from the Start menu. |
| Windows, no install | `AcademicJobTracker-…-windows-x64.zip` | Unzip, then double-click **Start Job Tracker.bat**. |
| Mac with Apple chip (M1 or newer) | `AcademicJobTracker-…-macos-apple-silicon.zip` | Unzip, then **right-click** **Start Job Tracker.command** → *Open* → *Open* (needed the first time only, because the app is not signed by Apple). |
| Older Intel Mac | `AcademicJobTracker-…-macos-intel.zip` | Same as above. |

The tracker opens in your web browser. Keep the small window that starts with it open while you use it.

**Your progress is kept outside the program folder** (Windows `%APPDATA%\AcademicJobTracker`, Mac
`~/Library/Application Support/AcademicJobTracker`), so to update you simply install or unzip the new version.
To use several computers, open *Data & sources → Where your progress is stored* and pick the same cloud-drive
folder (iCloud Drive, OneDrive, Dropbox, Google Drive, Nutstore) on each.

The job list refreshes itself from this repository every week.
